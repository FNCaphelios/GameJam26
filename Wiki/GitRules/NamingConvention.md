# Sprache
Es werden alle internen Dokumente auf deutsch verfasst. (Meeting-Protokolle, Regelwerke, Wissenseinträge, ...) 
Die Codebasis und weitere externe Dokumente werden auf englisch verfasst. (Methodennamen, Codekommentare, ReadMes, ...)

# Namensgebung
Wir halten uns an die standardmäßige Clean-Code-Konventionen.
Das heißt:
  - Methodennamen sollten deskriptiv sein.
  - Methodennamen sollten im Camelcase geschrieben sein (dasIstEinBeispielDafür)
  - Konstante werden in Capslock geschrieben
  - Jede Methode sollte einen Kommentar nach folgenden Muster haben:
      Kurze Beschreibung
      @param Name + Beschreibung des Parameters
      ...
      @return Beschreibung der Rückgabe
  - Versucht sauber zu arbeiten bitti bitti :3
